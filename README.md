# skincare-risk-project
NLP and machine learning pipeline for predicting skincare product reaction risk from reviews and ingredient data.
# Predicting Skincare Reaction Risk Using NLP & Machine Learning

## Overview
This project develops a machine learning pipeline to identify
skincare product reaction risk using consumer reviews and
ingredient information.

## Dataset
- 1M+ consumer reviews
- 2,400+ skincare products
- Ingredient-level product information

## Methods
- NLP feature engineering
- Negation-aware concern detection
- K-means clustering
- Principal Component Analysis (PCA)
- Multinomial Logistic Regression

## Results
The final model used 6,000+ ingredient features and achieved
approximately 65% classification accuracy.

## Technologies
Python, pandas, NumPy, scikit-learn, Jupyter Notebook
